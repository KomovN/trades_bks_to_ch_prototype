## Prompt

```bash
make tasks
make prompt TASK=T02
```

Генератор печатает самостоятельный brief с границами, входными документами,
требованиями и проверками. Он не запускает агентов и не меняет статусы.
Для задачи с незавершёнными зависимостями запуск prompt завершается ошибкой.

Owner — конкретный агент/исполнитель; сейчас `null`. Назначающий координатор
меняет owner/status, фиксирует результат в журнале и ссылку evidence. Отдельные
исполнители предлагают изменения реестра в отчёте, когда координатор ведёт общие файлы.
`done` допускается только после фактической проверки и с существующим evidence-файлом.
`kind` различает contract, implementation и review. Итоговая review-задача не
засчитывается как единственный исполнитель функционального требования.

## Разделение файлов

После T02 задачи T03 и T04 могут выполняться независимо. T05 и T06 независимы
после их зависимостей. Общие файлы Makefile, pyproject, CI, registry и plan
интегрирует координатор; каждый исполнитель указывает нужный patch в отчёте.
T07 вправе согласованно доработать интерфейсы writer/reader при последовательной
интеграции. Не создавайте много работающих копий документации без необходимости.

Обязательный формат отчёта: scope → результат → выполненные команды/exit codes →
evidence → not run/риски → следующий шаг. Не считать написанные тесты пройденными.
Подробный отчёт сохраняется в `tasks/reports/Txx.md` при выполнении задачи.
