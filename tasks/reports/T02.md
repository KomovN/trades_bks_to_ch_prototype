# T02 — Python-каркас, settings и подписка

Статус: выполнено. Owner: `/root/t02_foundation`.

## Результат

- Добавлен installable package для Python `>=3.12,<3.13`; прямые зависимости
  зафиксированы в `pyproject.toml`, весь реально установленный граф — в
  `constraints.txt`.
- `Settings.from_env()` проверяет все переменные из env-контракта до сети:
  наличие токена и YAML, строгий bool, finite/range constraints, безопасные
  identifiers, `wss`/loopback `ws`, взаимные ограничения reconnect/shutdown.
  Значения токенов и ClickHouse password исключены из repr; тексты ошибок не
  содержат входных значений.
- `load_settings()` поддерживает необязательный `.env`, причём process env имеет
  приоритет.
- Safe YAML loader отклоняет duplicate/unknown fields, unsafe tags и неверные
  типы. Loader проверяет точный snapshot из 101 пары по числу и SHA-256 без
  изменения регистра и строит wire JSON с `subscribeType=0`, `dataType=2`.
- Pytest markers `integration` и `live` зарегистрированы; unit tests не используют
  сеть, БКС или ClickHouse.

## Исправление по результатам T09

T09 обнаружила расхождение с общим budget из `docs/specs/reliability.md`:
индивидуальные лимиты допускали одновременно connect=10 и I/O=10. Валидация теперь
отклоняет конфигурацию, если сумма `CLICKHOUSE_CONNECT_TIMEOUT_SEC` и
`CLICKHOUSE_IO_TIMEOUT_SEC` превышает 15 секунд. Ровно 15 секунд разрешены;
defaults 5+10 остаются валидными. Ограничение явно добавлено в таблицу конфигурации.
