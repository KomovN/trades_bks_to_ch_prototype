# T08 — Docker, локальный ClickHouse и runbook

Дата: 2026-10-17. Owner: `/root/t08_deployment`.

## Результат

- Добавлен multi-stage `Dockerfile` на Python 3.12.13. Runtime работает под uid/gid
  10001; test stage добавляет только pytest, migration и integration tests. Полный
  dependency graph зафиксирован `constraints.txt`.
- Production `docker-compose.yml` содержит только `trades-ingestor`: без host ports,
  ClickHouse или `container_name`; subscription bind read-only, root filesystem
  read-only, `stop_grace_period: 60s`, ограниченные json-file logs.
- `.dockerignore` исключает `.git`, `.env*`, caches/logs/build и Harness-документы;
  context ограничен текущим репозиторием.
- Local Compose использует project-scoped network/volume без опубликованных портов и
  pinned `clickhouse/clickhouse-server:24.8.4.13`. Отдельный `ch-init` создаёт
  `trades_integration` и применяет неизменённый DDL; повторный init ничего не удаляет.
- `scripts/init_clickhouse.py` выполняет отдельный database/table init и безопасную
  диагностику `--check`: version/timezone, `SHOW CREATE TABLE`, count/max timestamp
  без печати credentials. Отдельный real-CH test запускает именно CLI-команду и
  проверяет отсутствие test password в stdout/stderr.
- `scripts/run_integration.sh` собирает образы, ждёт healthcheck, запускает init,
  S15 и container smoke. Любая ошибка даёт nonzero; trap удаляет только containers/
  network project-а и сохраняет test volume (нет `-v`).
- S15 дважды выполняет канонический DDL на настоящем CH, проверяет engine,
  partition/sort/primary keys, DateTime64 UTC, codecs, exact raw JSON, усечение к
  миллисекундам и две физические одинаковые строки.
- Container smoke запускает настоящий `python -m app.main` subprocess внутри test
  image. Локальный fake WebSocket проверяет synthetic Bearer и подписку на 101 пару,
  отдаёт одну сделку; тест ждёт строку в настоящем CH, посылает SIGTERM и проверяет
  clean exit без утечки token.
- README/runbook теперь содержат build/start/stop/init/check/rollback/local cleanup.
  Production CH и quotes-сервис не использовались и не изменялись.

CPython 3.12.13, pytest 9.1.1.

- `PYTHON=.../python make check` — exit 0, Harness `9 tasks, 16 requirements,
  17 acceptance scenarios`.
- `sh -n scripts/run_integration.sh` и `git diff --check` — exit 0.
- `scripts/run_integration.sh` — exit 0 после запуска координатором с доступом к

## Ограничения и следующий шаг

- `24.8.4.13` — локальная compatibility baseline. Версия и DDL production ClickHouse
  по-прежнему неизвестны (Q01) и проверяются перед rollout, без применения migration
  к внешнему серверу в T08.
- Live BKS не использовался. S17 остаётся отдельной проверкой T09 по явному поручению.
- Координатору после успешного integration: заменить `make integration` на
  `scripts/run_integration.sh`, добавить обязательный integration job в CI и отметить
  T08 `done` с evidence `tasks/reports/T08.md`.
