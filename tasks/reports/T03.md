# T03 — Parser и bronze row

Дата: 2026-10-17. Owner: `/root/t03_parser`.

## Результат

- Реализован чистый `parse_message(raw_msg, *, source, received_at)`: он не читает
  часы, сеть или ClickHouse и использует переданный reader-ом `received_at`.
- Реализован порядок классификации T01: строгий decode/JSON object, приоритет
  заполненного `error`, допустимые responseType, точное множество discriminator-ключей
  `{side, price, quantity}`, затем metadata сделки.
- `str` frame сохраняется посимвольно, а `bytes` декодируется строгим UTF-8 без
  replacement. Parser не выполняет `strip`, `json.dumps`, преобразование цены,
  количества или неизвестных полей.
- `ticker` и `classCode` принимаются только как непустые строки без surrounding
  whitespace. `dateTime` требует `Z` или явный offset. `event_time` и
  `received_at` переводятся в UTC и усекаются до миллисекунд.
- Добавлены immutable dataclasses `TradeRawRow` и `ParseResult`. Только результат
  `trade` содержит row; код source error извлекается только как настоящий JSON
  integer из object, без coercion и без включения raw frame в reason.
- 43 parser-теста покрывают 17 fixtures T01, raw fidelity, строгий UTF-8/JSON,
  временные зоны, миллисекунды, неверную metadata, precedence ошибок и
  неизменяемость результата.

## Публичный интерфейс для T05/T06

```python
@dataclass(frozen=True, slots=True)
class TradeRawRow:
    received_at: datetime
    source: str
    ticker: str
    class_code: str
    event_time: datetime
    raw_json: str

@dataclass(frozen=True, slots=True)
class ParseResult:
    kind: Literal[
        "trade", "control", "other", "malformed", "malformed_trade", "source_error"
    ]
    row: TradeRawRow | None = None
    error_code: int | None = None
    reason: str | None = None

def parse_message(
    raw_msg: str | bytes, *, source: str, received_at: datetime
) -> ParseResult: ...
```

Пример row после разбора frame с `dateTime=2026-03-13T18:09:45.123456+03:00`
и переданным `received_at=2026-10-17T15:34:56.987654+03:00`:

```python
TradeRawRow(
    received_at=datetime(2026, 10, 17, 12, 34, 56, 987000, tzinfo=timezone.utc),
    source="bks",
    ticker="SBER",
    class_code="TQBR",
    event_time=datetime(2026, 3, 13, 15, 9, 45, 123000, tzinfo=timezone.utc),
    raw_json=raw_msg,  # исходный text frame без повторной сериализации
)
```

T06 должен передавать aware `received_at`, зафиксированный сразу после `recv()`.
Naive/non-datetime `received_at` и неверный `source` являются нарушением интерфейса
reader-а и вызывают `ValueError`; ошибки самого frame возвращаются в `ParseResult`.
T05 может использовать поля row в согласованном порядке INSERT:
`received_at, source, ticker, classCode, event_time, raw_json`.
